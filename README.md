# Single-Responsibility Lab

### Currency Conversion App 

Create a Currency Conversion app to convert USD to Pesos, Yen, or Euros. Your app should do the following:

- Welcome the user and displays a menu with options to convert the amout to a) Pesos, b) Yen, or c) Euro.

- Ask the user to input a Dollar (US) amount

- Ask the user to input their choice.

- Convert USD to the selected currency and display it to the user.

Build this app using the **Single-Responsibility Principle**.
